# v0.7 — Encyclopedia design and usability

Reworked the public wiki using the existing FYI Guildmaster Simulator stylesheet as the design reference: slate-black backgrounds, antique gold, serif display type, compact controls and bordered panels. Added a restrained decorative geometric brand mark and kingdom accent colors (presentation only, not canonical heraldry). Homepage contains actual corpus statistics, six kingdoms, featured lore and category cards. Added `/kingdoms`, ranked Unicode-normalized full-text search with category filter and safe snippets, random article redirects, alphabet navigation, category highlights, responsive article panels, section contents, scope metadata and grouped relationship links. All 202 article records, 271 original sections, 884 links, aliases, categories and prior routes are untouched. No login, CMS, external font, client-side framework, or new lore. Image production remains for a later phase. Build runs regression and layout-structure tests; browser screenshot inspection is separate from automated HTML checks.
