# v0.6 — Unified public encyclopedia

Author directed removal of the unnecessary author access barrier. 202 encyclopedia articles, 271 original prose sections, 442 relationship pairs (884 reciprocal links), and all 32 previously published article URLs are preserved. Publication does not constitute canon approval: existing canon and scope labels remain. Public-only schema retains title, canonical ID, slug, category, description, section headings/text, related IDs, and publication status. No aliases added. Raw manuscripts, underlying source files, evidence indexes, internal decision records, credentials, and player records are not imported into GitHub or the image. Existing author endpoints redirect to the public directory or return not found; authentication and import code removed from runtime. Existing volume is left intact to avoid destructive deletion. The original archive remains the authoritative backup.
