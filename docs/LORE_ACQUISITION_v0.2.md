# v0.2 — Lore acquisition checkpoint

## Acquired
The author-side register contains four distinct source files: three story/world sources and one editorial reference. One identical duplicate was excluded by SHA-256. The archive preserves 2,628 raw text lines across 179 indexed sections and 79 category-specific candidate article entries. 75 entries have literal source mentions; four require further evidence. These are candidate entries, not published articles or independently confirmed facts.

The seven previously published geography stubs have been checked against the foundational mythology and their kingdom-identity claims are established. No further lore has been published in this release.

## Authority
- Latest author-designated manuscript controls story contradictions.
- Latest explicit author decisions govern details not settled in manuscript.
- Approved series/world canon fills gaps.
- Style guidance is editorial, not factual canon.
- Proposals, open questions and assistant alternatives must not be silently canonized.

## Publication boundary
The repository is public. Do not commit the private acquisition register, source snapshots, private links, unpublished plot points, or manuscripts. Git history is public even if a file is later deleted. Keep private sources separately and publish only reviewed, spoiler-cleared summaries with source labels suitable for a public audience.

## Remaining work
11 source groups remain outstanding or unaudited, including revised historical and mythology references, additional manuscripts, game canon, and visual materials. Source discovery is partial, not an exhaustive audit. Article population is a later phase; claim-level review and source reconciliation remain necessary.

## Import handoff
Each private source record has an ID, filename, hash, authority and acquisition status. Sections carry exact source line ranges; candidate articles include category, title, review status, publication hold and source mentions. A literal mention is not proof of an approved claim. The private author-side ZIP is the acquisition deliverable and is intentionally not committed.
